# Brew Brain Funding & Prototyping Roadmap (0 to Series A)

## Objective
Map product milestones to capital raises and non-dilutive startup credit programs.

## The 24-Month Roadmap

### Phase 0: Prototyping & Bootstrap (Months 1–6)
*   **Goal:** Build the "Walking Skeleton" (Flask API + InfluxDB + Grafana + Prediction Models).
*   **Status:** [COMPLETED] - Basic stack is functional and deployed on Raspberry Pi 5.
*   **Available Startup Programs to Activate immediately:**
    *   AWS Activate Founders ($1k) or Google Start ($2k).
    *   GitHub Free, Stripe Startups.

### Phase 1: Pre-Seed / Beta (Months 6–12)
*   **Goal:** Deploy to 5 core beta testers (Commercial & Advanced Homebrewers). Refine FG prediction accuracy. Harden security (RBAC, API tokens).
*   **Funding Status:** **Pre-Seed ($250k - $500k)**. Safes from Angel Syndicates/Micro-VCs. Transitions dev from AI to a human engineering team.
*   **Startup Programs:** Apply to tier-one accelerators (Y Combinator, Techstars) to unlock "Institutionally Backed" status.

### Phase 2: Seed Round & Commercial Launch (Months 12–18)
*   **Goal:** Launch v1.0. Commercial subscription model. Onboard first 50-100 users. Build enterprise dashboard for multi-fermenter tracking.
*   **Funding Status:** **Seed Round ($1M - $3M)** from Institutional VCs.
*   **Startup Programs:** Upgrade AWS Activate to **$100,000** or Google Scale to **$200,000**.

### Phase 3: Series A & The AI Pivot (Months 18–24+)
*   **Goal:** Global GTM. Predictive models for global style benchmarking. Yeast health analytics as a service.
*   **Funding Status:** **Series A ($10M+)**.
*   **Startup Programs:** Apply for the **$350,000** Google AI Track to cover compute costs for ML training on millions of anonymized batches.
