# Brew Brain Issue & Feedback Tracker

Use this document to capture any bugs, glitches, or user experience (UX) improvements you encounter while using Brew Brain. 

When you find an issue, simply add it to the top of the **Open Issues** list using the format below. The AI Agent will review this file periodically or when asked to "fix open bugs".

## Template
```markdown
- **[Date] Issue Title**
  - **Type:** [Bug | UX | Feature Request]
  - **Where:** [e.g., Kiosk Page, Inventory Scanner, Mobile Safari]
  - **What happened:** [Describe the unexpected behavior]
  - **Expected:** [What should have happened instead]
```
