# PRD & Functional Spec: Automation - Recipes (Module 6.1)

## 1. Executive Summary
This sub-module acts as "The Chef". It ingests external recipe data (BeerXML 2.0 or Brewfather links), normalizes the format, and cross-references the requirements against the current Inventory (Module 6.3) to generate an actionable "Ingredient Deficit".

## 2. Dev Team & Persona
*   **Lead Software Developer:** Implements the XML parsing logic and API endpoints.
*   **UX/UI Designer:** Designs the recipe preview and deficit modal.

## 3. Functional Specifications

### 3.1 BeerXML 2.0 Parsing
*   **Engine:** Replace the legacy regex-based parser in `services/scout.py` with the `lxml` library for robust, standard-compliant DOM traversal.
*   **Data Normalization:** External recipes use various units (lbs, oz, kg, g, gallons, liters). The parser must instantly convert all incoming metrics to standard SI units (Liters, Kilograms, Grams) for the Brew-Brain database.
*   **Scale-Up Checking:** Cross-reference the recipe's expected boil volume and grain bill against the physical limits of the Grainfather G40. Flag if `grain_weight > 12kg` or `boil_volume > 40L`.

### 3.2 The "Ingredient Deficit" Calculator
*   Upon parsing a recipe, this module must call `GET /api/automation/inventory`.
*   It subtracts the recipe requirements from the available inventory.
*   It outputs a "Deficit Report" identifying exactly what is missing to brew this batch.

## 4. API Contracts

### `POST /api/automation/recipe/parse`
Ingests an XML file or Brewfather ID and returns the normalized recipe and the deficit.
**Request:**
```json
{
  "source": "brewfather",
  "recipe_id": "xyz123"
}
```
**Response:**
```json
{
  "status": "success",
  "recipe_name": "Juicy NEIPA",
  "warnings": ["Grain bill exceeds G40 maximum efficiency threshold (8kg+)"],
  "deficit": {
    "hops": [
      {"name": "Citra", "amount_needed_g": 100, "amount_in_stock_g": 50, "deficit_g": 50}
    ],
    "fermentables": [
      {"name": "Flaked Oats", "amount_needed_kg": 1.0, "amount_in_stock_kg": 0.0, "deficit_kg": 1.0}
    ]
  }
}
```

## 5. UI Requirements
*   **Recipe Import Modal:** Shows the calculated OG/FG/IBU based on local Brew-Brain math vs. the original author's targets.
*   **Deficit Alert:** Highlights missing ingredients in red and provides a "Send to Sourcing" CTA to hand off the deficit to Module 6.2.
