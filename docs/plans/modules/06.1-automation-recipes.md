# PRD & Implementation Plan: Automation - Recipes (Module 6.1)

## 1. Executive Summary
This sub-module of Automation handles the ingestion and analysis of external recipe data.

## 2. Technical Decisions
*   **Parsing:** Implement a dedicated **BeerXML 2.0 Parser** in `services/scout.py`.
*   **Intelligence:** Cross-reference external recipes with the local **G40 Hardware Profile** to flag scale-up issues automatically.

## 3. Implementation Plan
1.  **Backend Fix:** Fix the brittle regex-based XML parsing; use `lxml` for robust node traversal.
2.  **UI Upgrade:** "Recipe Import" modal with a preview of calculated SG/IBU compared to the original author's targets.

## 4. Pros & Cons
*   **Pros:** Seamless integration with Brewfather and external sources.
*   **Cons:** XML is a legacy format with many non-standard implementations (Beersmith vs Brewfather).

## 5. Stability Fixes
*   Fixes "Parser Error" when importing recipes with special characters or unexpected units (lbs vs kg).
