# PRD & Functional Spec: Automation - Simulation & R&D (Module 6.4)

## 1. Executive Summary
This sub-module acts as "The Data Scientist". It provides "Dry Run" capabilities to simulate a brew day before committing physical inventory. By leveraging historical telemetry data from InfluxDB and Monte Carlo simulation techniques, it predicts probable outcomes (e.g., terminal gravity, chance of stall) specific to the user's hardware.

## 2. Dev Team & Persona
*   **Data/Analytics Analyst:** Defines the statistical models and queries InfluxDB for historical yeast performance.
*   **System Architect:** Implements the Celery task queue to offload heavy simulation processing from the main thread.

## 3. Functional Specifications

### 3.1 Historical Data Engine (InfluxDB)
*   The module queries the `fermentation` bucket in InfluxDB to extract historical attenuation rates for the specific yeast strain declared in the recipe.
*   If no local historical data exists for a specific yeast, the engine must fall back to the manufacturer's stated median attenuation with a wider variance factor.

### 3.2 Monte Carlo Simulation
*   **Mathematical Model:** Run 1,000 iterations of the recipe's expected attenuation, varying variables like Mash Temperature (±1°C), Pitch Rate, and Yeast Health.
*   **Celery Background Tasks:** Monte Carlo math is CPU-heavy. The simulation must run in `worker.py` (Celery). The UI will poll or wait for a WebSocket completion event.

### 3.3 LLM Stress Test (The AI Brewmaster)
*   The statistical output of the simulation is passed to the Llama3 Edge AI.
*   The AI acts as the final judge, generating a human-readable "Stress Test Report" (e.g., "Warning: SafAle US-05 has a 15% probability of stalling at 1.020 given this high-gravity wort").

## 4. API Contracts

### `POST /api/automation/simulate`
Takes a normalized recipe and triggers the background simulation.
**Request:**
```json
{
  "recipe_name": "Juicy NEIPA",
  "target_og": 1.065,
  "yeast": "WLP066",
  "mash_temp_c": 68
}
```
**Response:**
```json
{
  "status": "queued",
  "task_id": "sim_abc123"
}
```

### `GET /api/automation/simulate/status/<task_id>`
Returns the results of the Monte Carlo simulation and the LLM analysis.
**Response:**
```json
{
  "status": "completed",
  "data": {
    "predicted_fg_mean": 1.014,
    "predicted_fg_p5": 1.010,
    "predicted_fg_p95": 1.018,
    "llm_analysis": "Based on 4 previous batches with WLP066, you are likely to finish higher than expected. Consider lowering mash temp to 66°C to increase fermentability."
  }
}
```

## 5. UI Requirements
*   **Possibility Graph:** A visual bell curve showing the distribution of likely Final Gravities.
*   **AI Insights Panel:** A clean, markdown-rendered summary of the LLM's stress test report.
