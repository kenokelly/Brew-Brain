# PRD & Implementation Plan: Automation - Simulation & R&D (Module 6.4)

## 1. Executive Summary
This sub-module uses AI and historical data to simulate "What-If" scenarios for new recipes.

## 2. Technical Decisions
*   **Engine:** Use **Monte Carlo Simulations** to predict the range of likely terminal gravities based on historical yeast performance in YOUR brewery.
*   **LLM Role:** The AI Brewmaster acts as the "Stress Tester," flagging recipes that are likely to overflow the fermenter or stall.

## 3. Implementation Plan
1.  **Backend Fix:** Move simulation logic out of the main API thread into a background **Celery Task** to prevent UI hangs.
2.  **UI Upgrade:** "Possibility Graph" showing the bell curve of predicted outcomes.

## 4. Pros & Cons
*   **Pros:** Scientific recipe de-risking.
*   **Cons:** Highly dependent on the amount of historical data in InfluxDB.

## 5. Stability Fixes
*   Fixes the crash when attempting to simulate a recipe with zero historical matches for the yeast strain.
