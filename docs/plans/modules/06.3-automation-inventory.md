# PRD & Functional Spec: Automation - Inventory (Module 6.3)

## 1. Executive Summary
This sub-module tracks the physical stock of hops, grains, and yeast. It acts as the "Warehouse" of the Brew-Brain system, maintaining the ground truth of available ingredients. It integrates bi-directionally with the Brewfather Inventory API and tracks ingredient degradation over time.

## 2. Dev Team & Persona
*   **System Analyst:** Designs the data schema and API boundaries.
*   **DevOps Specialist:** Handles external API rate-limiting, error retries, and network resilience.

## 3. Functional Specifications

### 3.1 Brewfather API Synchronization
*   **Bi-Directional Sync:** Changes made in Brew-Brain (e.g., consuming ingredients after a brew day) must push to Brewfather. Changes in Brewfather must pull down to Brew-Brain.
*   **Rate Limiting (429 Errors):** Brewfather API has strict rate limits. The sync engine must implement exponential backoff and retry queues.
*   **Name Normalization:** Implement a string-distance algorithm (e.g., Levenshtein) or regex-stripping to handle name mismatches (e.g., "Citra" vs "Citra Pellets" vs "Citra (US)").

### 3.2 Waste & Expiration Management
*   **Hop Degradation:** Utilize the existing `calculate_hop_freshness` function from `hop_math.py`. When a hop is queried, its *current* alpha acid must be dynamically calculated based on its purchase date and storage condition (Freezer, Fridge, Ambient).
*   **Low Stock Alerts:** Set configurable thresholds (e.g., Base Malt < 5kg, Hops < 50g) that trigger UI alerts and feed into the Sourcing Module (6.2).

## 4. API Contracts

### `GET /api/automation/inventory`
Returns the current local inventory, calculating real-time hop degradation.
**Response:**
```json
{
  "status": "success",
  "data": {
    "hops": [
      {
        "id": "123",
        "name": "Citra",
        "amount": 250,
        "unit": "g",
        "original_alpha": 12.5,
        "current_alpha": 11.2,
        "storage": "freezer"
      }
    ],
    "fermentables": [],
    "yeasts": []
  }
}
```

### `POST /api/automation/inventory/sync`
Triggers a background job to sync with Brewfather.
**Response:** `{"status": "queued", "job_id": "xyz"}`

## 5. UI Requirements
*   **"Inventory Low" Widget:** A dashboard component that flags items below their safe threshold.
*   **"Re-order" Button:** A one-click CTA next to low items that packages the deficit and sends it to the Sourcing module.
