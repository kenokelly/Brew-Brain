# PRD & Implementation Plan: Automation - Inventory (Module 6.3)

## 1. Executive Summary
This sub-module tracks the physical stock of hops, grains, and yeast.

## 2. Technical Decisions
*   **Sync Logic:** Bi-directional sync with **Brewfather Inventory API**.
*   **Waste Management:** Automated expiration tracking for hops based on the **HSI (Hop Storage Index)** formulas already in the library.

## 3. Implementation Plan
1.  **Backend Fix:** Fix the data-mismatch where certain hops wouldn't sync due to naming differences (e.g., "Citra" vs "Citra pellets").
2.  **UI Upgrade:** "Inventory Low" dashboard widget.
    *   One-click "Re-order" button that feeds into the Sourcing module.

## 4. Pros & Cons
*   **Pros:** Prevents "Brew Day Stalls" due to missing ingredients.
*   **Cons:** Requires manual initial count to seed the database.

## 5. Stability Fixes
*   Fixes the silent failure during sync when the Brewfather API returns a 429 Rate Limit error.
