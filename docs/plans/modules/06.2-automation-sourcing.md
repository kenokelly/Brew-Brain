# PRD & Functional Spec: Automation - Sourcing & Pricing (Module 6.2)

## 1. Executive Summary
This sub-module acts as "The Procurement Agent". When the Recipes Module (6.1) or Inventory Module (6.3) flags a deficit, this module automates the cost-analysis by hitting external vendor search APIs. It calculates the cheapest multi-vendor basket to fulfill the deficit.

## 2. Dev Team & Persona
*   **System Architect:** Designs the API boundaries and caching strategy.
*   **Lead Software Developer:** Implements the `ThreadPoolExecutor` async requests and the multi-vendor optimization algorithm.

## 3. Functional Specifications

### 3.1 External API Integration (SerpApi)
*   **Engine:** Use SerpApi's Google Shopping integration to find real-time prices for brewing ingredients.
*   **Caching Strategy:** To prevent exhausting the SerpApi free-tier, all successful search results must be cached in Redis with a 24-hour TTL.
*   **Parallelization:** Searching for 5 missing ingredients sequentially is too slow. The backend must use `concurrent.futures.ThreadPoolExecutor` to execute all vendor searches in parallel, returning the aggregated result to the UI.

### 3.2 Multi-Vendor Optimization Algorithm
*   A simple greedy algorithm: If Vendor A has Hops for $5 but Malt for $30, and Vendor B has Hops for $10 but Malt for $15, the module must calculate whether the combined shipping costs outweigh splitting the order.
*   (V1 Phase: Simple cheapest-per-item selection with preferred vendor weightings).

## 4. API Contracts

### `POST /api/automation/source`
Takes an array of deficit items and returns a sourced shopping cart.
**Request:**
```json
{
  "deficit": {
    "hops": [{"name": "Citra", "deficit_g": 50}],
    "fermentables": [{"name": "Flaked Oats", "deficit_kg": 1.0}]
  },
  "preferred_vendors": ["The Malt Miller", "Crossmyloof"]
}
```
**Response:**
```json
{
  "status": "success",
  "total_estimated_cost": 15.50,
  "currency": "GBP",
  "cart": [
    {
      "item": "Citra 100g Pellets",
      "vendor": "Crossmyloof",
      "price": 5.50,
      "link": "https://..."
    },
    {
      "item": "Flaked Oats 1kg",
      "vendor": "The Malt Miller",
      "price": 10.00,
      "link": "https://..."
    }
  ]
}
```

## 5. UI Requirements
*   **Price Tracker Dashboard:** A clean data-table showing the deficit items and the "Best Found Price".
*   **Preferred Vendor Badges:** Visually distinguish results from trusted vendors versus unknown Google Shopping results.
