# PRD & Implementation Plan: Automation - Sourcing & Pricing (Module 6.2)

## 1. Executive Summary
This sub-module automates the cost-analysis of recipes.

## 2. Technical Decisions
*   **Search Engine:** Utilize **SerpApi (Google Shopping)** for real-time local availability.
*   **Optimization:** Implement **Multi-Vendor Basket Optimization** (calculating the cheapest way to buy ingredients across 3+ UK vendors).

## 3. Implementation Plan
1.  **Backend Fix:** Parallelize search requests using `ThreadPoolExecutor` to prevent UI timeouts (the "Sourcing is Offline" bug).
2.  **UI Upgrade:** "Price Tracker" dashboard.
    *   Add "Preferred Vendor" badges.

## 4. Pros & Cons
*   **Pros:** Significant cost savings on high-gravity batches.
*   **Cons:** SerpApi has a cost per search (Free tier is limited).

## 5. Stability Fixes
*   Implementation of a result cache to prevent hitting API rate limits during a single session.
